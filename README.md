# NLP Exercises

This project contains a Jupyter Notebook `task.ipynb` with solutions to various NLP exercises.

## Setup

1.  Create a virtual environment:
    ```bash
    python -m venv venv
    source venv/bin/activate
    ```

2.  Install dependencies:
    ```bash
    pip install pandas jupyter nltk scikit-learn
    ```

## Running the Exercises

1.  Launch Jupyter Notebook:
    ```bash
    jupyter notebook
    ```

2.  Open `task.ipynb` and run the cells sequentially.

## Note on Data

The file `tweets_train.txt` was not provided, so a dummy placeholder file has been created to allow the code to run. You should replace this file with the actual dataset when available. The code assumes each line in the text file is a separate tweet.
